# Prompt Marketplace

A beginner-friendly React + TypeScript app created with Vite and styled with Tailwind CSS.

## Scripts

- `npm run dev` starts the local development server
- `npm run build` creates a production build
- `npm run preview` previews the production build locally
- `npm run lint` runs ESLint

## Project structure

- `src/main.tsx` boots the React app
- `src/App.tsx` contains the homepage UI
- `src/index.css` loads Tailwind CSS and global styles
